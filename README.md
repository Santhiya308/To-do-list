📝 To-Do List Web Application

A simple and user-friendly To-Do List Web Application that helps users add, manage, and complete their daily tasks.

🚀 Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- View all tasks in one place
- Simple and clean user interface
- Easy to use

🛠️ Technologies Used

- HTML – Structure of the application
- CSS – Styling and layout
- JavaScript – Functionality and task management

📂 Project Structure

To-Do-List/
│
├── index.html
├── style.css
├── script.js
└── README.md

▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in any web browser.
4. Start adding and managing your tasks.

💡 How It Works

1. Enter a task in the input box.
2. Click the Add Task button.
3. The task will appear in the task list.
4. Mark the task as completed when finished.
5. Delete the task when it is no longer needed.

🎯 Project Objective

The main objective of this project is to create a simple task management application and practice basic HTML, CSS, and JavaScript concepts.
